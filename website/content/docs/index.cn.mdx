## 什么是 Prime-Agent Session Manager？

Prime-Agent Session Manager 是一款跨平台 Prime-Agent Web UI，用于浏览、搜索和管理 Prime-Agent、[Pi](https://github.com/badlogic/pi-mono) 及其他 Coding Agent 会话。它基于 Dwsy 创建的 [Pi Session Manager](https://github.com/Dwsy/pi-session-manager)，可作为原生桌面应用、响应式 Web 应用和无头服务器运行。

> "最好的工具是那种不会妨碍你的工具。" — Jef Raskin

无论你是在回顾过去的对话、在数百个会话中搜索特定代码片段，还是在看板上追踪 AI 辅助开发工作流，Prime-Agent Session Manager 都能让工作保持连贯。

### 核心能力

- **会话浏览器** — 列表、项目、目录和看板视图，支持收藏、批量导出和多路径扫描。查看 [会话浏览器](./session-browser)。
- **搜索与回溯** — SQLite FTS5、角色过滤、会话 ID 匹配、片段高亮和命令面板搜索。查看 [搜索系统](./search)。
- **仪表板与分析** — 活动热力图、项目分布、模型使用、Token 消耗和成就追踪。查看 [仪表板](./dashboard)。
- **API 与自动化** — HTTP、WebSocket 和 SSE 共享同一命令路由，便于程序化访问。查看 [API 参考](./api)。
- **扩展系统** — 内置、npm 和本地路径插件，配套浏览器插件 SDK，可扩展应用视图、命令、工具和设置。查看 [扩展 README](https://github.com/dat-lequoc/prime-agent-session-manager/blob/main/extensions/README.md)。
- **Pi Live 与桥接同步** — 实时会话同步、上下文回溯、标签和基于桥接的 Pi CLI 工作流。查看 [psm-bridge](./plugins/psm-bridge)。
- **终端与工作区工具** — 内置 PTY 终端、会话恢复、层级标签和多平台支持。查看 [终端](./terminal) 与 [标签](./tags)。

## 快速安装

### 桌面应用

从 [GitHub Releases](https://github.com/dat-lequoc/prime-agent-session-manager/releases) 下载本分支适合你平台的最新版本：

| 平台 | 文件 |
|------|------|
| macOS (Apple Silicon) | `Prime.Agent.Session.Manager_*_aarch64.dmg` |
| macOS (Intel) | `Prime.Agent.Session.Manager_*_x64.dmg` |
| Windows (x64) | `Prime.Agent.Session.Manager_*_x64-setup.exe` / `.msi` |
| Linux | `.deb` / `.AppImage` / `.rpm` |

### CLI / 无头服务器

从同一发布页面下载 `pi-session-cli` 二进制文件，或使用 Docker 构建：

```bash
docker build -f Dockerfile.cli -t pi-session-cli .
docker cp $(docker create pi-session-cli):/pi-session-cli ./pi-session-cli
chmod +x pi-session-cli
./pi-session-cli
```

<Callout type="tip">
交互式静态 Demo：[打开浏览器 Demo](https://dat-lequoc.github.io/prime-agent-session-manager/demo/)

上游静态数据集版：[https://dwsy.github.io/pi-session-manager/dataset/](https://dwsy.github.io/pi-session-manager/dataset/)
</Callout>

<Callout type="info">
会话恢复和终端集成需要安装 Pi。请从 [github.com/badlogic/pi-mono](https://github.com/badlogic/pi-mono) 安装。
</Callout>

## 首次启动

1. **打开应用** — 自动扫描 `~/.pi/agent/sessions/` 中的会话
2. **浏览会话** — 在列表、项目、目录或看板视图之间切换
3. **搜索** — 按 `Cmd/Ctrl + K` 打开命令面板，或 `Cmd/Ctrl + F` 进行侧边栏搜索
4. **查看会话** — 点击任意会话，打开带有树形导航和流程可视化的查看器
5. **打开终端** — 按 `Cmd/Ctrl + J` 切换内置终端
